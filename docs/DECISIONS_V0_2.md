# v0.2 decisions

1. Station discovery is the first feature after the fixed-catalogue MVP.
2. Radio Browser is the first provider, behind a replaceable adapter boundary.
3. Production discovery accepts HTTPS stream URLs only.
4. Presets store full canonical station records.
5. The UI presents one search result at a time to preserve the blind-first interaction model.
6. Search never starts playback implicitly.
7. DIAL remains static, local-first, framework-free, and backend-free for this milestone.
